# Предметное решение по нормативному пункту

В нормативной форме включите «Добавить предметное решение». Укажите проверяющего, дату проверки, дату оцениваемой работы, основание редакции и её действия на эту дату, применимость, состояние исходных данных, решение, мотивировку и ограничения. Сначала выберите точные источники нормы и факта. Расширенный JSON поддерживает несколько якорей, source/authority receipts и отдельные ограничения.

|Поле|Допустимые значения|
|---|---|
|applicability|APPLIES,UNKNOWN,OUT_OF_SCOPE,CONFLICT|
|input_status|DOCUMENTED,UNVERIFIED,MISSING,CONFLICT|
|outcome|PASS,WARNING,UNCERTAINTY,ERROR,BLOCK|
|reviewed_at / assessment_date|ГГГГ-ММ-ДД; assessment_date≤reviewed_at≤сегодня|

Записанное решение и эффективный статус показываются отдельно. Неизвестная область, редакция или исходные данные не исчезают после сохранения. Источники со сканами/неоднозначными координатами сохраняют штатные NEEDS_DATA gates. PASS/ERROR требуют документированных применимых данных и при неподтверждённых полномочиях проверяющего остаются UNCERTAINTY. Инженерное принятие и FINAL AUDIT выполняются отдельным контуром.

Новый пакет одинакового документа/редакции/пункта/области/набора фактов является новой версией. Другие пункты или фактические группы видны одновременно. Изменение оригинала, решения source review или основания chain/review аннулирует пригодность сохранённого решения. Полный компактный индекс сохраняется при сокращении подробностей для контекста модели.

Для воспроизведения частного manifest с точными originals:

```bash
python -m scripts.replay_normative_review --manifest PRIVATE_REVIEW.json --source-dir ORIGINALS --output NEW_DIRECTORY
```

Manifest содержит sources с key/name/sha256, candidates с key/source/page/quote/statement/data_class/decision/note и packets с ссылками на ключи candidates. Полные формы пакетов совпадают с обычным API domain-packets. Новый каталог обязателен. Несовпадение SHA останавливает импорт. Реальные original bytes, source provenance и source-review gates проверяются обычным приложением; автоматическое подтверждение ручной транскрипции не допускается. result.json содержит результат и подтверждение равенства после повторного открытия; data содержит историю. Replay не запускает модель или solver.
