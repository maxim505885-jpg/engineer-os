document_analysis PARTIAL, FINAL AUDIT NOT_RUN, acceptance=false. Queue SUCCEEDED
означает, что итог с ошибками сохранён, а не что роли выполнены. Таймаут runtime
не является доказанной инженерной ошибкой объекта. Скорость генерации на этом
CPU наблюдалась около2–3tokens/s; поведение на другом оборудовании не измерено.

Модель/OCR benchmark suites запускались последовательно в отдельных процессах;
комбинированный маршрут скан→Docling→Qwen также выполнен.
CHAT по контрольному скану правильно прочёл 4м, 2этажа, кирпич (152.44s).
CHAT по scan таблице и V4 таблице завершились FAILED: model calls длились
180.11/180.12s, что соответствует лимиту ожидания gateway180s; общее время
190.58/198.45s включает OCR. Ответы не получены, оценка реакции модели на
повреждённую подпись и чтения реальной таблицы невозможна. Во всех проверках
cgroup oom/oom_kill=0; это не гарантирует работу при иной нагрузке. Во время native model проверки
RSS llama-server наблюдался около6,1GiB; это выборка, не peak. Значение
memory.current включает file cache и не является RSS приложения.

## Телеметрия и проверка исправления

Первый OCR запуск был отклонён автоматической проверкой безопасности из-за
Microsoft telemetry. Состав payload не установлен. Незащищённый запуск не
повторялся. Согласно официальным документам ORT, ORT_DISABLE_TELEMETRY=1 до
initialization отключает uploader/events/device identifier на non-Windows.
Защищённый новый процесс выставлял это значение до импортов, а также HF offline
и HF telemetry opt-out; веса находились локально. Реальный ORT import и все
восемь extraction jobs выполнены после этого opt-out.

Adapter выставляет переменную до optional imports и дополнительно вызывает
platform API disable_telemetry_events. Предварительно загруженный ORT без текущего
opt-out блокируется с требованием перезапуска. Историю окружения чужого раннего
импорта он установить не может. Windows startup-event suppression не доказана.
[Подробности и официальный источник](docling-privacy.md).

strace/ptrace запрещён средой; сетевой аудит всего процесса не выполнен.
Opt-out не объявляется firewall и не является гарантией для всех зависимостей.

Regression: сначала два теста дали три ожидаемых RED failure, после исправления
GREEN; итог332Python tests, 4Node tests, compileall и diff check. Независимое
read-only ревью четырёх файлов privacy fix не нашло actionable findings.
Тесты минимального окружения не заменяют измерение качества живого OCR.
