# Пункт 5 — анализ, источники и требования ТЗ

Кабинет сохраняет версионированный перечень требований ТЗ, выводы и ссылки на кандидатов источников. Перечень составляется пользователем: одна строка — требование. Новая версия не переносит прежние статусы; прежние версии и история выводов остаются в SQLite. До50 требований/2000символов каждое,20версий/диалог; вывод≤2000символов, до20разных кандидатов,50ревизий/требование и1000записей/диалог. Revision guards отклоняют конкурирующее сохранение.

Маршрут интерфейса: открыть результаты по части → выбрать место → точная цитата из извлечения, не ответ модели → заполнить запись и заявленный тип P/F/M/T/C/A/I/U → сохранить кандидата → сверить источник → связать с требованием и выводом. Сохранение кандидата и проверка требуют отдельного действия, модель не создаёт accepted evidence. Формы сохраняют черновик/фокус/выделение при polling. После reload сохранённые требования/история/решения восстановлены.

Office candidates привязаны к extraction child/logical unit и серверному locator. DOCX/XLSX цитата повторно читается из неизменённого оригинала, XML locator и checkpoint text сверяются; SHA проверяется и для фактически прочитанных байтов. Повторяющаяся цитата, BLOCK элемента, клиппинг, чужая сессия или изменённый parser/source/derivative не могут пройти подтверждение. DOC locator относится к сохранённой производной копии; даже точное совпадение не подтверждает оригинальный DOC. Непроверенная производная location имеет SOURCE_LOCATION_UNVERIFIED, изменение hash/location — отдельную причину SOURCE_IDENTITY_OR_LOCATION_CHANGED. PDF native quote/provenance/preview path сохранён.

Gate каждого требования показывает цитату, место, исходный hash, заявленный тип, revision source review и причины. Изменение/отклонение source review инвалидирует прежнюю связь; источник вне выбранных материалов явно SOURCE_NOT_SELECTED. SUPPORTS/CONTRADICTS/UNKNOWN — пользовательские декларации; противоречие остаётся BLOCK, а не доказанным дефектом объекта. SOURCE_LINKED означает прослеживаемую source-reviewed цитату, но статус всегда UNCERTAINTY: ENGINEERING_VERIFICATION_REQUIRED, DATA_CLASS_NOT_VERIFIED. Нормы/измерения/расчёты и применимость цитаты не подтверждены.

CHAT/CORE получают bounded перечень с раскрытием усечения; полный текущий report сохраняется отдельно от model text. CORE findings проходят отдельный deterministic source gate и показываются в интерфейсе. Голый file ID не считается проверенным доказательством. Identity включает requirements и все зависимые evidence/source reviews, включая кандидатов из невыбранных файлов. Изменения во время model call дают FAILED; изменённое основание запрещает resume. Старые результаты имеют снимок на момент задания; актуальная проверка показана в текущем перечне.
