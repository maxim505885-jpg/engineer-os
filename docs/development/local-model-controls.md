# Модель и задачи в локальном кабинете

Откройте «Локальная модель · настройки и проверка» возле состояния соединения. Укажите локальный адрес, имя установленной модели, провайдер, режим рассуждения и тайм-аут. «Сохранить и применить» сохраняет настройки текущего каталога данных; перезапуск не требуется. Дождитесь завершения или отмены активных задач во всех проектах. Настройки, заданные окружением запуска, имеют приоритет; кабинет объяснит отказ при попытке их изменить. Секретный ключ здесь не редактируется и не сохраняется.

«Модель найдена» означает только наличие в списке сервера. «Проверить реальный ответ» создаёт отдельный диалог без ваших документов и прежней истории. Результат или ошибка появляются в его задачах. Успешный ответ не подтверждает инженерную компетентность модели.

«Отменить» снимает ожидающее задание с очереди. Для выполняющегося задания кабинет показывает запрос отмены и держит очередь занятой до возврата текущего вызова. Сохранённые материалы остаются; поздний ответ не добавляется в историю. HTTP-тайм-аут ограничивает ожидание приложения, но не обещает остановить вычисления на стороне движка.

«Повторить новым заданием» сохраняет прежнее задание и снова ставит его запрос в очередь. Для частично обработанных документов предпочтительнее «Продолжить извлечение» или «Продолжить анализ»: эти действия проверяют идентичность исходников/настроек и используют сохранённый журнал без сброса бюджета. Повтор может использовать обновлённые требования проекта; прежний результат остаётся историческим снимком.

В Linux проверены Ollama0.34.4 и qwen3:8b, thinking=false; подробности и ограничения — в docs/qa/2026-10-08-local-model-task-controls.md. Нативный Windows проверяется отдельно по №16 плана. При недоступном Drive можно прикреплять оригиналы вручную.
