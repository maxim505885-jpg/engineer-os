## Реальный бесплатный путь

Официальная Ollama **0.34.4**, **qwen3:8b**, CPU, контекст сервера 2048, thinking=false. Веса получены из официального registry; SHA256 всех config/layers сверены с manifest, основная модель `sha256:a3de86cd1c132c822487ededd47a324c50491393e6565cd14bafa40d0b8e686f`.

`e2e/local_model_live_smoke.cjs` через настоящий Chromium: отсутствующая модель → изменение настроек из кабинета → модель найдена → отдельный диагностический диалог → реальный непустой ответ → перезагрузка и сохранность ответа → загрузка TXT → реальный ответ по источнику и сохранённое покрытие. PASS, synthetic_model=false. Инженерное принятие false, ответы остаются NOT_EVIDENCE. Проверка транспорта не оценивает инженерное качество модели или полноту больших документов.

Предварительная проверка qwen3:0.6b прямым запросом на 0.34.4 также завершилась. На 0.40.1 в этой среде загрузчик qwen3:0.6b не завершился за отведённое время; успешного вывода на этой версии не заявляем. Одинаковые проверенные веса работали на 0.34.4. Причину внутри нового загрузчика не установили; результаты нельзя переносить на все компьютеры. Обновление Ollama не является условием запуска приложения.

## Ошибки и управление задачами

- Сервер недоступен и модель отсутствует различаются; наличие модели не выдаётся за проверенное выполнение запроса.
- Тайм-аут 1–600 секунд применяется к модельному запросу и входит в идентичность продолжения. Запрос с реальной задержкой HTTP проверен: FAILED, исходный ввод сохранён, повтор создаёт новое задание.
- QUEUED отменяется до выполнения. RUNNING сохраняет активный слот с CANCEL_REQUESTED до возврата запроса; поздний ответ не публикуется в историю. Отмена не обещает немедленного прекращения вычислений внутри Ollama.
- Повтор FAILED/CANCELLED создаёт новое задание; старые записи остаются. Для извлечения используется прежний журнал продолжения, без сброса лимитов.
- Отмена после сохранённой страницы/части анализа → продолжение того же задания: завершённые страницы и модельные части не повторяются, идентичность проверяется.
- Настройки применяются только при отсутствии активных задач во всех проектах. Запись атомарная; адрес только loopback; ключи не сохраняются; значения, закреплённые окружением запуска, нельзя незаметно переопределить.
- HTTP проверяет токен и принадлежность задания проекту.

В приложении нет доступного подключения Drive (APP_DRIVE_CONFIGURED=false). Реальные OAuth/import не проверены; контролируемая проверка происхождения оригинала, изоляции и отказа по SHA256 проходит. Это явно открытый подпункт, разрешённый критерием №5 при отсутствии подключения. Windows — №16. Большие инженерные документы — №6, качество ядра — №7, реальный принятый объект — №12.
