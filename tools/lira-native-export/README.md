# ENGINEER OS — выгрузка таблиц ЛИРА 2024

Распакуйте архив полностью. Запустите START.cmd и выберите исходный .lir. На рабочем столе появится ENGINEER_OS_LIRA_EXPORT_….zip; отправьте его в чат. Если возникла ошибка, отправьте ENGINEER_OS_LIRA_EXPORT_ERROR_….json.

Используется установленная ЛИРА2024 и её COM-регистрация. Python и платные AI API не требуются. ЛИРА может открыться автоматически; окно необходимо оставить до завершения выгрузки. Если COM не зарегистрирован, ошибка будет записана; инструмент не меняет регистрацию и не запускает установки.

Инструмент открывает отдельную копию модели. Через CreateNewItem создаёт табличные представления всей загруженной схемы и через GetContents читает TSV без ограничения длиной предпросмотра. Все31 типа из фактически установленного LiraTableEnum (2–32) запрашиваются отдельно; ошибки каждого типа сохраняются. Создание таблицы ввода меняет представление в памяти копии, но SetContents/Apply/Save не вызываются. Копия не сохраняется из ЛИРА. Исходник проверяется по SHA256 до/после. RestoreEnv=0 не восстанавливает вложенные дополнительные файлы грунта. Копия остаётся отдельно на рабочем столе, в ZIP она не входит.

ZIP содержит TSV и manifest.json: идентичность исходника, метаданные документа, фактические коды единиц, сообщения открытия, ошибки и SHA256 каждой таблицы. Числовые коды единиц сопровождаются api_enumerations в manifest.json; API-контракт получен из присланного инвентаря ЛИРА2024.

Это начальная частичная выгрузка модели, НЕ вся информация файла. Таблицы с особыми параметрами выгружаются только с параметрами по умолчанию; существующие сохранённые таблицы не копируются отдельно; записи нагрузок, варианты РСН, грунт, произвольные бинарные разделы и результаты ещё не извлекаются полностью. Результаты расчёта и solver не запускаются; full_information_extracted/results_exported/acceptance_granted=false. Интеграция этого экспортёра в сайт пока не выполнена.

Windows CI проверяет механизм на моделях интерфейсов, без установленной ЛИРА. Совместимость фактического GetContents/OpenDocument и полнота данных проверяются реальным запуском на ПК пользователя.

## Версия2

В первом реальном запуске модель открылась, но все31 таблицы получили «Несовпадение типов», ZIP содержал только manifest. Точный этап ошибки в версии1 не записывался. Версия2 использует C# COM bridge: пропущенный Pars передаётся как Missing (VT_ERROR/DISP_E_PARAMNOTFOUND), GetContents/GetParameters — через явный by-reference ParameterModifier. Добавлены error_stage и HRESULT каждой ошибки. При нуле экспортированных таблиц статус теперь TABLE_EXPORT_FAILED. Это проверка обоснованной гипотезы о marshaling; реальная совместимость ЛИРА ещё требует повторного запуска.
