# ENGINEER OS — определение интерфейса ЛИРА

Распакуйте оба файла в одну папку и запустите `START.cmd`. Инструмент сам ищет работающую ЛИРА и стандартные каталоги 2024/2025/2026. На рабочем столе появится ZIP с `lira-api-inventory.json`; отправьте ZIP в чат.

Это определение точных методов установленной версии, **не извлечение модели**. Инструмент читает встроенные библиотеки типов EXE/DLL/TLB через Windows LoadTypeLibEx с REGKIND_NONE. Программу ЛИРА не запускает, расчёт не выполняет, исходные модели не меняет, COM-регистрацию не изменяет. JSON содержит пути/версии библиотек, SHA256, интерфейсы, методы, параметры и константы. Библиотеки самой ЛИРА в ZIP не копируются.

Если найдено API_NOT_FOUND, укажите установленную папку вручную:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\engineer_os_lira_api_probe.ps1 -InstallDir "C:\Program Files (x86)\LIRA SAPR\LIRA SAPR 2024\Bin\x64"
```

На основе инвентаря следующий адаптер сможет использовать точные методы открытия копии LIR и выгрузки таблиц. Доступность модели и результатов должна проверяться отдельно; полнота и инженерная корректность не подтверждаются наличием API.
