# Report Review Skill

## Purpose

Audit technical reports against the supplied ТЗ and source materials.

## Checks

- ТЗ coverage;
- factual consistency;
- evidence traceability;
- engineering terminology;
- internal contradictions;
- normative references;
- calculation references;
- conclusion proportionality;
- spelling and grammar when requested.

## Rules

A report that is correct and complete may receive PASS/ACCEPTED without edits.

Do not create artificial defects, errors, or recommendations.

Use ERROR only for a demonstrated error. Use UNCERTAINTY when evidence is insufficient.
