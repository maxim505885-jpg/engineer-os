# ENGINEER OS Skills

Skills are reusable workflow instructions for specialist engineering tasks.

Each skill should contain:
- SKILL.md — concise workflow and activation rules;
- optional scripts/resources;
- explicit inputs and outputs;
- validation rules;
- links to the relevant source-of-truth documentation.

Initial skills:
- inspection-audit
- report-review
- normative-check
- calculation-review
- final-audit

Keep skills focused. Do not put the entire engineering methodology into every skill.
