# Calculation Review Skill

## Purpose

Review structural calculation inputs, model assumptions, and interpretation of results.

## Minimum review

- geometry;
- materials and sections;
- loads/combinations;
- supports/releases;
- boundary conditions;
- units;
- solver warnings/errors;
- result interpretation;
- correspondence to actual structure.

## Rule

A calculation result is not independently trustworthy merely because software produced it.

If required model data are unavailable, emit UNCERTAINTY or BLOCK as appropriate.
