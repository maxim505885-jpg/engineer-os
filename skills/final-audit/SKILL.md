# Final Audit Skill

## Purpose

Verify that an ENGINEER OS deliverable is internally consistent, traceable, and ready for release.

## Required state

Before FINAL_AUDIT:
- ТЗ addressed;
- evidence traceable;
- facts separated from assumptions;
- conclusions proportional to evidence;
- normative references verified;
- calculations verified or explicitly marked unverified;
- no unresolved ERROR or BLOCK;
- residual WARNING/UNCERTAINTY items disclosed;
- changes traceable.

FINAL_AUDIT is a verification state, not a quality score.
