# Normative Check Skill

## Purpose

Verify that a cited normative requirement is applicable and correctly used.

## Workflow

document → edition → scope → clause → requirement → actual condition → comparison → conclusion

## Rules

- Never invent clause numbers or wording.
- Verify document applicability.
- Distinguish current requirements from historical requirements.
- If exact verification is unavailable, mark UNCERTAINTY.
- Do not treat a citation as proof that the cited requirement applies.
