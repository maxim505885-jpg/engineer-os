## Персональная инженерная AI-платформа

ENGINEER OS — проект системы интеллектуальных агентов для анализа обследований зданий и сооружений, проверки технических отчетов, работы с нормативной базой, накопления инженерного опыта и автоматизации инженерных задач.

## Основные направления

- ENGINEER CORE — главный инженерный агент
- Document Intelligence — анализ документов
- Knowledge Base — инженерная база знаний
- Training Center — обучение агентов
- Autonomous Engine — выполнение задач без постоянного присутствия инженера
- Report Generator — формирование технических документов
- CAD Agent — инженерная графика и CAD-направление
- Multi AI Connector — подключение нескольких AI-моделей

## Принципы

1. Факт важнее предположения.
2. Вывод должен соответствовать уровню доказательности.
3. Не создавать неподтвержденные дефекты и причины.
4. Проверять применимость нормативных документов.
5. Сохранять историю решений и изменений.

## Локальный кабинет

После [подготовки окружения](docs/development/local-environment.md) двойной щелчок по `Start_ENGINEER_OS.cmd`: чат с локальной моделью, оригиналы файлов, история на диске и фоновые задачи. Выбранный PDF автоматически обрабатывается при отправке задачи. [Запуск, настройки и границы проверки](docs/development/local-app.md). Бесплатный режим не требует облачной базы; нужны Ollama, Python 3.12+ и зависимости requirements-local-app.txt. Живая модель/OCR и Windows ещё требуют проверки.

## Резервное копирование данных

`Backup_ENGINEER_OS.cmd` создаёт проверяемую копию локальных данных приложения, а `Restore_ENGINEER_OS.cmd` выполняет fail-closed восстановление только после проверки SHA256/SQLite integrity. Подробности: [Reliability / Backup / Restore](docs/development/reliability-backup-restore.md).
