Резервные копии и восстановление

К начальной странице

На Windows: остановите кабинет через Stop_ENGINEER_OS.cmd, затем откройте Recover_ENGINEER_OS.cmd двойным щелчком. Модель и очередь здесь не запускаются.

Проверяем режим…

1. Копия и проверка

Копируется вся локальная база: проекты, оригиналы, история и результаты. Архив приватный, не зашифрован; может содержать ключ локального издателя. Проверка целостности не удостоверяет создателя архива.

Каталог данных:

Для новой копии выберите ещё не существующий файл вне каталога данных. Путь можно скопировать из Проводника.

2. Восстановление

Укажите доверенный архив выше и новый каталог ниже. Существующий каталог не заменяется. Прежний проект сохраняется для отката.

3. Выбор проекта для запуска

После восстановления выберите новый каталог для обычного запуска. Для отката можно выбрать прежний каталог. Файлы не перемещаются.

После успешного выбора закройте режим обслуживания и откройте Start_ENGINEER_OS.cmd. Вес модели и внешние программы в архив не входят.
